TERRAFORM for AWS EKS
=================

Description: 
-------------

For this project I used Terraform to launch a kubernetes cluster on AWS EKS as well as multiple other resources on AWS.
Created a .tf file to launch the VPC, defined all the VPC components in the .tf file.
Created a .tf file for the EKS cluster.

Tools: 
------
S3 bucket on AWS
AWS EKS
Kubernetes
VPC
Subnets
Internet Gateway
Route Tables
EC2 instances
Key Pair
Security groups

1. Launch of infrastructure with terraform
2. Provision a kubernetes cluster for the application using Amazon EKS
